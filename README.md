# amadeos-system

The system components of [amadeOS](https://github.com/amadeos-eu/amadeos), built together as one Gradle
multi-project: one module and one Debian package per component. The standalone applications
(amade-files, amade-web, amade-pad, ...) keep their own repositories; the
[amadeos](https://github.com/amadeos-eu/amadeos) repository builds the live image from all packages.

## Modules

| Module | Package | What it is |
|---|---|---|
| `base` | (in every desktop package) | The library under the desktop modules: Xlib, Xss, Xkb, libc and PAM through JNA, the EWMH client helper, launch feedback and the lock selection, XDG directories and `.desktop` files, theme, icons and backdrops, the process and lock launchers, the session dialogs, the network service and the bell. Nothing in it depends on the other modules; they all depend on it |
| [`wm`](wm/README.md) | `amadeos-wm` | The window manager: a floating, reparenting X11 window manager with Motif/CDE frames, four workspaces and the root menu (`amadeos-wm [display]`) |
| [`panel-cde`](panel-cde/README.md) | `amadeos-panel-cde` | The CDE Front Panel: clock, calendar, workspace switch (buttons in the theme's workspace colours), lock and language buttons, network cell, sound cell (volume, output and input device through `pactl`), battery cell (shown only with a battery: fill green, yellow at 50 % and below, red at 20 % and below, a bolt on mains power, percentage and time left in the tooltip), notifications cell (a bell with the count of unseen notifications, crossed out during Do not disturb; a click shows the history, the menu has Do not disturb, Clear all and the settings), updates cell (shown while updates wait: count, red for security updates, menu with Install all / Install security updates only / Check now) and the drawers of installed applications. Provides `amadeos-panel`, the panel the session starts |
| `panel-horizon` | `amadeos-panel-horizon` | The top bar and the dock of the Horizon look. The dock: favourite and running programs (dot for running, ring for minimised; Keep in dock in the right-click menu, `~/.config/amadeos/dock.conf`), the program drawers, Downloads and Documents with their newest files, the Trash; minimised windows go into it (`_AMADEOS_DOCK_TAKES_MINIMIZED`). The top bar: system menu (About, Programs by category, Files, Settings, Software, Task Manager, Lock screen, Log out or shut down), the active program's name with a minimise/close menu, workspace dots, the Front Panel's status cells, a magnifier for the search and a clock that opens the Calendar. A screen button left of the workspace dots and the dock's right-click menu show the desktop (Super+D). The search (Super+Space, which the window manager hands over the `amadeos-search` socket of `InstanceChannel`): programs, Settings pages, files in the home folder and sums, in a frameless window (`_AMADEOS_FRAMELESS`). `amadeos-session` starts it instead of the Front Panel while `~/.config/amadeos/look.conf` says `look=horizon`; a panel exits with code 75 when the look changes and the session starts the other one |
| `widgets` | `amadeos-widgets` | The desktop widgets of Horizon: one host process that puts widget cards on the desktop below all windows (`_AMADEOS_DESKTOP_WIDGET`), with a gallery (`--gallery`, from the system menu and the dock menu). Built in: clock, photo frame, to-do note; applications add their own through `eu.amadeos.commons.widget.DesktopWidget` and a `.widget` file in `/usr/share/amadeos/widgets/` (Calendar ships a month widget). Layout in `~/.config/amadeos/widgets.conf`, the settings of each copy in `~/.config/amadeos/widgets/` |
| `icons-horizon` | `amadeos-icons-horizon` | The icon theme of the Horizon look, `amadeos-horizon` in `/usr/share/icons`: original icons for the amade programs and games, the desktop's tools, program groups, places, devices and file types (rounded tiles with a soft horizon, blue folders, pages with a coloured band), drawn in Java2D (`HorizonIcons`) and written as PNG files from 16 to 256 pixels when the package is built; other names for the same icon are symbolic links. It inherits NsCDE and hicolor. Horizon uses it unless an icon theme is chosen for Horizon (`icons=` in `look.conf`); the classic look keeps its own (`icon_theme.conf`) |
| `dm` | `amadeos-dm` | The display manager: `amadeos-dm.service` starts Xorg and the login greeter, which authenticates through PAM in a root worker and starts the session (`amadeos-dm [display]`; `amadeos-dm greeter` shows the greeter alone) |
| `session` | `amadeos-session` | The X session (`amadeos-session`: window manager under supervision, autostart scripts, then the panel), the screen lock (`amadeos-session lock`, wrapped by `amadeos-lock`), the screen saver with idle lock (`amadeos-session screen`), the polkit agent (`amadeos-session polkit-agent`) the clipboard manager (`amadeos-session clipboard`, its history shown by `amadeos-clipboard`) and the notification service (`amadeos-session notifications`, its history shown by `amadeos-notifications`) |
| `settings` | `amadeos-settings` | The Settings, formerly the Style Manager (CDE's dtstyle: Color, Font, Backdrop, Keyboard, Mouse, Beep, Screen, Window, Notifications and Clipboard), and the input settings tool (`amadeos-settings input`, run at login) |
| `logviewer` | `amadeos-logviewer` | Session Diagnostics & Logs: the session, window manager and application logs, the display manager's logs and the journal of this boot, one at a time with Follow; started from the panel's Tools drawer |
| `print` | `amadeos-print` | Print manager: CUPS printers with their state, the jobs of each printer (cancel, hold, release), pause and resume printers, default printer, test page, CUPS administration for adding printers |
| `sysinfo` | `amadeos-sysinfo` | System information: operating system, processor, memory, storage, graphics, network and battery on one page; copy or save as text |
| `taskmanager` | `amadeos-taskmanager` | Task Manager: the program windows (status, workspace, CPU, memory and disk of each program's processes; Switch To, End Program), all processes as a tree or a list (end, force end, pause and continue, priority, properties; other users' processes through `pkexec`) and the last minute of processor, memory, network and disk as graphs, all read from `/proc`. Ctrl+Shift+Esc and Ctrl+Alt+Del open it (window manager keys); the window manager also starts it with `--not-responding WINDOW` when a window stops answering |
| `packages` | `amadeos-packages` (helper only; the library is in the packages that use it) | Package management for the update cell and the Software program (ROADMAP M15): `PackageService` reads upgrades, installed and available packages and the catalog sorted into categories, and searches, with apt as the user, and installs, upgrades and removes through the root helper `/usr/libexec/amadeos-packages` with progress. The only module that talks to apt |
| `software` | `amadeos-software` | Software: finds, installs, updates and removes software. Tabs Applications, Command line, Other and (with *Show libraries*) Libraries, with one search and an *All / Installed* filter over them; the package's description next to the list with Install, Remove and Update, and a question before anything else gets installed or removed with it. The Updates tab appears while updates wait (security updates first, *Install selected* or *Security updates only*); the front panel's updates cell opens it (`--updates`, `--settings`). A progress bar with the apt log, a restart bar when an update needs one, and the setting for automatic security updates. The tabs come from AppStream data (package `appstream`), the files of installed packages, and else the Debian section. Applications show their AppStream icon, name and summary in the user's language; the details are rendered as XHTML (Flying Saucer, as in amade-web) with the description and the application's screenshot, downloaded from the distribution's media server into `~/.cache/amadeos-software`. Packages that no repository's AppStream data knows (the amade applications and games, a .deb installed by hand) get name, summary, icon and group from their installed desktop entry and hicolor icon, and description and screenshots from their `/usr/share/metainfo/*.metainfo.xml`. When there are no package lists yet (the image is built without them), Software fetches them once at start; that needs no password |

The desktop code came from the amadeos repository with its history (`git filter-repo`); that
repository keeps the live image and its configuration. A module's `packaging/root` is a file system
tree that goes into its package (files under `etc/` as conffiles), `packaging/debian` holds its
maintainer scripts.

## The desktop

The desktop is the five packages `amadeos-dm`, `amadeos-session`, `amadeos-wm`, `amadeos-panel-cde` and
`amadeos-settings`, each a jar under `/opt/<package>/` with the launcher `/usr/bin/<package>`; the programs
of the Tools drawer (`amadeos-logviewer`, `amadeos-sysinfo`, `amadeos-taskmanager`) and `amadeos-print` are packages of their own
that the panel starts. `amadeos-dm`
depends on `amadeos-session`, which depends on `amadeos-wm` and on `amadeos-panel`. `amadeos-panel` is a virtual
package: `amadeos-panel-cde` provides it and registers `/usr/bin/amadeos-panel` as an alternative, and
`amadeos-session` starts that. A second panel (say a taskbar) provides `amadeos-panel` the same way and
takes the Front Panel's place when installed instead; with both installed, `update-alternatives` or
`AUTOSTART_APP` in `session.conf` chooses. The window manager treats any window of type
`_NET_WM_WINDOW_TYPE_DOCK` as the panel and knows none by name.

| Component | Package | What it does |
|---|---|---|
| **Display manager** | `amadeos-dm` | Started by `amadeos-dm.service` once Xorg runs on VT 7. Shows the login greeter (language and time zone of the session, the keyboard layout from the xkeyboard-config list, starting with the computer's own from `/etc/default/keyboard`, power actions), authenticates through PAM (`/etc/pam.d/amadeos-dm`) in a root worker process, opens a logind session and starts `amadeos-session` as the user. As root it points `/etc/localtime` at the chosen zone and writes `/etc/timezone`. |
| **Session** | `amadeos-session` | `/usr/bin/amadeos-session`: the window manager under supervision, the scripts of `/etc/amadeos/autostart.d` and `~/.config/amadeos/autostart.d` (except those switched off in Settings > Startup), the user's programs of `~/.config/autostart` (`amadeos-session autostart`), then the panel. Settings in `/etc/amadeos/session.conf`, overridden by `~/.config/amadeos/session.conf`. Registered as `x-session-manager`, so `startx` without the display manager starts the desktop too. |
| **Window manager** | `amadeos-wm` | A floating, reparenting X11 window manager (Xlib via JNA) with Motif/CDE-style frames (the button at the left of the title bar opens CDE's window menu: Restore, Minimize, Maximize, Lower, Close; a double click on it closes), interactive move (an outline or, as chosen in Settings > Window, the window itself) and resize, click or point to focus, minimize to desktop icons, four virtual workspaces, a desktop root menu and the EWMH/ICCCM hints that panels and toolkits rely on (`_NET_CLIENT_LIST`, `_NET_ACTIVE_WINDOW`, `_NET_CURRENT_DESKTOP`, `_NET_WM_STRUT_PARTIAL`, `WM_DELETE_WINDOW`, ...). It pings the active window with `_NET_WM_PING` every 2 seconds and every window that is asked to close; a window that does not answer within 5 seconds gets "(Not Responding)" in its title and the property `_AMADEOS_NOT_RESPONDING`, and the Task Manager asks whether to wait or end the program. Ctrl+Shift+Esc and Ctrl+Alt+Del open the Task Manager. |
| **Front panel** | `amadeos-panel-cde` | A CDE-style dock with clock, calendar, workspace switcher, lock and language buttons, the network, sound and battery cells and drawers that list the installed applications from their `.desktop` files (File Manager, Text & Office, Mail & Internet, Sound & Video, Graphics, Games, Print Manager, Tools, Help). Text & Office lists the text editors and word processors, then the other `Office` entries such as the Calendar. The Tools drawer holds the terminals, the Settings, the clipboard history and the log viewer; the Help drawer opens the amadeOS User's Handbook (package `amadeos-handbook`, or its web copy) in the web browser, followed by the installed `Documentation` entries such as the Game Developer's Handbook. Programs started from the panel log to `~/.cache/amadeos/logs/<program>.log`. |
| **Horizon top bar** | `amadeos-panel-horizon` | The panel of the second desktop look, Horizon (Settings > Desktop look): a 30-pixel bar along the top with the system menu, the program name, workspace dots, the status cells, the search (Super+Space: programs, Settings pages, files, sums) and the clock. At the bottom a floating dock with the favourite and running programs, drawers, folders and the Trash; minimised windows go into the dock instead of onto the desktop. In Horizon the window manager draws flat frames with rounded corners (X Shape) and an accent line, keeps windows below the bar's top strut and refits open windows when the look changes. |
| **Desktop widgets** | `amadeos-widgets` | Cards on the Horizon desktop, always below the windows: a clock, a photo frame, a to-do note and the month of the Calendar with the next appointments. Add them from the gallery (system menu or dock menu > Widgets), drag them to move, the lower right corner to resize, right-click for their settings. Super+D, the screen button in the top bar or the dock menu hide all windows to show the desktop with its widgets (EWMH `_NET_SHOWING_DESKTOP`); clicking a program brings the windows back. |
| **Horizon icons** | `amadeos-icons-horizon` | The icon theme `amadeos-horizon` of the Horizon look: flat rounded tiles for programs, blue folders for places, pages with a coloured band for file types, PNG from 16 to 256 pixels; what it does not have comes from NsCDE and hicolor. Horizon takes it by default, the classic look keeps NsCDE; each look remembers its own choice. |
| **Settings** (formerly Style Manager) | `amadeos-settings` | One window with the controls in a sidebar (Appearance: Desktop look with the dock's icon size and parts, Color, Font, Backdrop, Workspaces, Front Panel; Input and Sound: Keyboard, Mouse, Beep; Desktop: Display, Screen, Window, Notifications, Clipboard, Startup; System: Passwords, Updates, Language), the control's page next to it and a search field above; View > Compact gives back CDE's row of controls, each in its own dialog. Color (palette with its four workspace colours, and the icon theme), Font (CDE's sizes 1 to 7, `~/.config/amadeos/font.conf`, followed by every amade application), Backdrop, Keyboard, Mouse, Beep, Display (resolution, refresh rate, rotation, on/off and arrangement of each monitor with `xrandr`, a 15-second *Keep these settings?* countdown, one layout per set of monitors in `~/.config/amadeos/display.conf`, set again at login by `amadeos-settings display-apply` from `/etc/amadeos/autostart.d/15-amadeos-display`; the window manager, the backdrop and the Front Panel follow a new screen size), Screen, Window (click or point to focus, raise when active, show contents during move; `~/.config/amadeos/window.conf`, followed by the window manager at once), Notifications (corner, how long, beep, Do not disturb with schedule and full screen, per program *Pop-up and history* / *History only* / *Off*; `~/.config/amadeos/notifications.conf`, followed by the notification service at once), Clipboard, Workspaces (names of the four workspaces, `~/.config/amadeos/workspaces.conf`), Front Panel (analog or digital clock, network, sound, battery, notifications and updates cells; `~/.config/amadeos/panel.conf`, followed by the panel at once), Startup (the user's programs in `~/.config/autostart`, optional desktop services switched off in `~/.config/amadeos/startup.conf`), Passwords (lock, unlock and change the password of the login keyring through the Secret Service), Updates (automatic security updates, waiting updates, *Open Software…*) and Language (desktop language, the system time zone through `timedatectl`) work. Writes `~/.config/amadeos/theme.conf`, which the window manager, the panel and every amade application follow. `amadeos-settings input` applies keyboard repeat and click, mouse handedness, double-click time and acceleration, and the bell from `~/.config/amadeos/input.conf` with `xset`, `xmodmap` and `xrdb`; run at login (`/etc/amadeos/autostart.d/10-amadeos-input`) and on Apply in the Settings. `amadeos-style` still starts the Settings. |
| **Screen saver** | `amadeos-session` | CDE's dtscreen: uses the X server's idle counter (MIT-SCREEN-SAVER, `libxss1`), shows a saver module (Qix, Swarm, Starfield, Floating Logo, Blank) and locks the screen after the configured time. Started by `/etc/amadeos/autostart.d/50-amadeos-screen`; settings in `~/.config/amadeos/screen.conf`. |
| **Polkit agent** | `amadeos-session` | Asks for the administrator's password when a program of the session needs it through polkit (Software installing or removing packages via `pkexec`, for example). The Motif dialog shows polkit's message, the user to authenticate as (a choice when there are several administrators), PAM's prompt and, under *Details*, the action and the command line. Registers with polkitd for the login session (`$XDG_SESSION_ID`) and again whenever polkitd restarts. Talks to polkit's helper through `/run/polkit/agent-helper.socket` (polkit 126 and later) or `polkit-agent-helper-1`. Started by `/etc/amadeos/autostart.d/30-amadeos-polkit-agent` (`amadeos-session polkit-agent`; `--process PID` serves one process instead, like `pkttyagent`). |
| **Clipboard manager** | `amadeos-session` | Watches `CLIPBOARD` through XFixes (`libxfixes3`) and reads every copy at once into a history of 5 to 100 entries (text, HTML, images, file lists), kept in memory only. When the program that copied closes, it takes the clipboard over, so the copy can still be pasted; programs that close right after copying hand the copy over through the freedesktop.org `CLIPBOARD_MANAGER`/`SAVE_TARGETS` convention. Copies marked as secret by a password manager (`x-kde-passwordManagerHint`, the nspasteboard.org types) are neither recorded nor kept. Ctrl+Alt+V or *Clipboard History* in the Tools drawer (`amadeos-clipboard`) shows the history with previews: Enter or 1 to 9 put an entry back on the clipboard; pause and clear are there too. Optionally records selected text (`PRIMARY`) and puts it on the clipboard. Started by `/etc/amadeos/autostart.d/40-amadeos-clipboard`; settings (Settings > Clipboard) in `~/.config/amadeos/clipboard.conf`. |
| **Notifications** | `amadeos-session` | The desktop's notification service: owns `org.freedesktop.Notifications` on the session bus (spec 1.2: body markup and links, actions, icons and `image-data`, urgency, `desktop-entry`, `transient`, `resident`), so Firefox, Thunderbird, `notify-send` and the amade programs show Motif pop-ups. Up to four at a time in a corner above the Front Panel, newest nearest the corner, six seconds unless the program asks otherwise, paused while the mouse is over them; critical ones have a red bar and stay. Pop-ups never take the focus. Every notification goes into the history (`amadeos-notifications`: today, yesterday, older; kept 7 days, at most 100, in `~/.cache/amadeos/notifications.json`), where its buttons still work while the program runs. Do not disturb (for an hour, until tomorrow, until turned off, on a schedule, while a window is full screen) sends them silently into the history; critical ones still show. The Front Panel's bell and `eu.amadeos.NotificationCenter1` (`/eu/amadeos/Notifications`: ShowHistory, ClearAll, SetDoNotDisturb, StateChanged) control it. The panel itself announces new updates. Started by `/etc/amadeos/autostart.d/45-amadeos-notifications`; settings (Settings > Notifications) in `~/.config/amadeos/notifications.conf`. |
| **Screen lock** | `amadeos-session` | Grabs keyboard and mouse and asks for the user's password (PAM, `/etc/pam.d/amadeos-lock`). `/usr/bin/amadeos-lock` is the wrapper that locks again if the lock process dies; the window manager (Super+L), the panel's lock button and the screen saver start it. |

Language: English, Deutsch, Français, Español, Italiano, chosen in the greeter or with the panel's
language button; both write `~/.config/amadeos/locale.conf`. The panel's texts are in
`panel-cde/src/main/resources/eu/amadeos/system/i18n/desktop*.properties`.

## Building

```sh
./gradlew build                 # all modules, with tests
./gradlew deb                   # build/distributions/amadeos-<module>_<version>_all.deb per module
./gradlew :print:installToAmadeOs   # one package into ../amadeos/config/packages.chroot/
./gradlew :sysinfo:run          # start a module from the build
./gradlew :panel-cde:run        # the front panel on your current desktop
./gradlew :settings:run         # the Settings
wm/run-xephyr.sh                # window manager and panel in a nested X server
dm/run-greeter.sh               # the login greeter in a nested X server (mock PAM, user amadeos / amadeos)
```

Java 25 and `dpkg-deb` (for the packages) are needed. The X11 integration tests of the window manager
and the lock start their own Xvfb and use `xmessage` as a test client (`xvfb`, `x11-utils`); on a
machine without a display run the tests under `xvfb-run -a`. One test of `base` is skipped unless the
`amadeos-backdrops-cde` package is installed. With
[amade-commons](https://github.com/amadeos-eu/amade-commons) checked out next to this repository, the build
uses that checkout (composite build); otherwise the version from JitPack named in `build.gradle`.

## amadeos-print and CUPS

amadeos-print talks IPP (RFC 8010/8011) to CUPS itself, without `lpstat` or `cancel`: over the CUPS socket
`/run/cups/cups.sock`, or `http://localhost:631` when there is no socket. On the socket CUPS asks who is
calling and amadeos-print answers with `PeerCred`, as libcups does; CUPS checks that against the socket's
peer credentials. So the owner of a job can cancel it, and members of the group `lpadmin` can pause,
resume and choose the default printer, without a password.

Printers are added in the CUPS web interface (*Printer > Add or Configure Printers…*); driverless network
and USB printers (IPP Everywhere, AirPrint) usually appear by themselves. The test page is printed through
the JDK's print service.
